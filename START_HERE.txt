EARTIFY — READY TO DEPLOY

1) Extract this ZIP.
2) Create a GitHub repository.
3) Upload the CONTENTS of the EARTIFY_GitHub_Deploy folder to the repository root.
   Important: server.js, Dockerfile, render.yaml, package.json, and public/ must be directly at the repository root.
4) In Render, choose New -> Blueprint and connect that GitHub repository.
5) Review the Starter web service and 1 GB persistent disk before applying. These are paid Render resources; check the current price in Render first.
6) After deployment, optionally add OPENAI_API_KEY in Render -> Environment to enable full AI chat and analysis. Never commit the key to GitHub.
7) Open the Render URL and test /api/health, account signup/login, planet lookup, research search, Cero, and file upload.

Read DEPLOY_TO_GITHUB_RENDER.md for the full checklist and limitations.
